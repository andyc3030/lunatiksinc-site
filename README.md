# lunatiksinc.com

The public LUNATIKS website, served by GitHub Pages at https://lunatiksinc.com.

Static HTML and one stylesheet. No scripts, cookies, analytics or outside resources. The `quickbooks/` pages are the addresses registered with Intuit for the Bookkeeper app; `quickbooks/callback.html` is the sign-in return page and must stay free of scripts.

Changes are approved by the owner before they are pushed. No client data, keys or secrets belong here.
